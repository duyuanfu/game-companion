# 游戏陪玩/开黑搭子微信小程序 (Game Companion)

本项目为一款游戏开黑陪练预约系统的完整设计与研发仓库。

### 📚 项目核心文档与设计
- [项目规划、核心痛点攻关方案与资质指南](./PAIN_POINTS_AND_BLUEPRINT.md)

### 💻 后端工程结构 (`server/`)
基于 **Java 17 + Spring Boot 3.2.5 + MyBatis-Plus** 搭建：
1. **SQL 放置规范**：已统一放置于 `server/src/main/resources/sql/init_schema.sql`，开箱即用。
2. **统一支付网关 (策略模式解耦)**：
   - 默认启用 `MockPaymentService`（开发环境免商户号一键模拟付款回调）。
   - 预留 `WechatV3PaymentServiceImpl`（营业执照与微信支付商户号下发后，填入配置无缝热切换）。
3. **消息通知中心 (`NoticeService`)**：
   - 微信服务号模板消息强提醒（无限制卡片直达）。
   - 手机短信通道兜底防漏单。
4. **订单核心业务流转 (`order`)**：
   - 指定陪玩下单。
   - 超时未接单自动流转至【派单大厅】。
   - 派单大厅基于 **Redisson 分布式锁 + 数据库乐观锁** 并发原子抢单（防超卖）。
   - 战绩凭证提交与结单收益清算。
5. **手机端小程序管理员工作台 (`admin`)**：
   - 手机端免单独开发 Web 后台，管理员在小程序内即可随时在线试听录音、核验段位凭证、快捷理由一键驳回/通过。
   - 手机端经营大盘（实时订单量、流水、平台抽佣）。

### 📱 前端小程序工程 (`miniapp/`)
基于 **Uni-app (Vue3 + TypeScript + Vite + Pinia)** 搭建：
- `pages/index/index.vue`：精选陪练师主页，带**原生音频试听控制条**（点击即听原声）、段位标签、预约入口。
- `pages/order/create.vue`：确认预约订单，支持数量加减、区服输入、**一键 Mock 模拟支付回调**。
- `pages/hall/index.vue`：公共派单广场，陪玩师实时并发抢单池。
- `pages/my/index.vue`：个人中心（**商业化渐进式分流架构**）：
  - 纯净客户视角：查看订单、订单状态过滤、联系客服；
  - 微信手机号授权：支持 `getPhoneNumber` 微信原生一键授权绑定，防漏单提醒；
  - 陪玩师进阶入口：未入驻时显示「成为开黑陪练师」，已入驻时显示「陪玩师接单工作台」；
  - 超级管理员隐蔽入口：仅 `role === 9` 可见，普通用户零感知。
- `pages/companion/apply.vue`：【陪玩师入驻申请】录音试听原声录制、段位截图上传、服务定价设置。
- `pages/companion/workbench.vue`：【陪玩师独立接单工作台】接单开关 (在线/勿扰)、收益提现、派单大厅快捷通道。

## 🔐 用户登录与手机号授权体系方案

本项目摒弃了传统的反人类“账号+密码”注册方式，采用微信生态最推崇的**两阶段阶梯式登录**：

```text
阶段一：进入小程序【静默登录】(零感知)
├── 用户首次打开小程序，调用 wx.login() 获取临时凭证 code
├── 后端自动换取 openid，并自动生成客户档案记录 (sys_user)
└── 客户端静默完成 Sa-Token 鉴权，用户可无门槛浏览陪玩师、在线试听原声录音

阶段二：产生核心交互时【微信手机号一键授权】
├── 触发场景：用户点击「立即预约下单」或「申请成为陪玩师」
├── 交互组件：微信原生 <button open-type="getPhoneNumber">
└── 核心优势：用户无需输入密码、无需等待短信验证码，手指点击“允许”即可 1 秒完成绑定。
    真实手机号用于订单到达时的短信外呼兜底提醒，彻底杜绝漏单。
```

### 方式 A：小程序端连击暗门（最推荐，随时随地手机切换）
1. 在手机或开发者工具中进入小程序 **「我的」** 个人中心；
2. 找到最下方的 **「版本信息 v1.0.0 (开发联调版)」**；

4. 点击「确定」，当前身份立即切换为管理员，页面最下方瞬间解锁并展示 **「超级管理员手机端工作台」** 入口，点击即可进入在线试听原声、查验段位截图、看经营大盘。

### 方式 B：数据库直改（企业级生产规范）
当你在微信中打开过一次小程序后，数据库 `sys_user` 表会自动建档生成你的记录，直接执行 SQL：
```sql
UPDATE sys_user SET role = 9 WHERE openid = '你的微信openid';
```
刷新个人中心后，底部会自动展现管理员特权入口。

## 📱 微信小程序手机号一键授权绑定机制与避坑说明（问题2解析）

在测试「点击绑定手机号」时，微信弹窗展示的手机号与数据库最终写入的号码可能存在差异，这是**微信小程序官方的安全隐私保护机制**所决定的：

### 1. 微信原生手机号授权的底层原理
1. 客户端点击 `<button open-type="getPhoneNumber">` 授权后，微信为了保障用户隐私，**绝对不会在前端 JS 里暴露明文手机号**；
2. 微信客户端只会向前端返回一个经过微信加密的动态凭证：`e.detail.code`；
3. 前端把这个动态 `code` 发给 Java 后端，**必须由后端拿小程序的 `AppID` + `AppSecret` 向微信官方服务器发起网络请求**（`https://api.weixin.qq.com/wxa/business/getuserphonenumber`），微信官方验签通过后，才会在服务端解密返回用户真实的手机号。

### 2. 为什么在开发调试期，数据库存入的号码会与弹窗展示的不一致？
* 在**本地开发测试阶段**，后端的 `application.yml` 中预留的微信密钥是占位符（`your-miniapp-secret`）；
* 当后端带着假 Secret 去微信服务器换取真实手机号时，微信官方接口会返回 `41002 (AppID/Secret 不匹配)`，导致无法解密出微信弹窗里的那个真实号码；
* 为了保证你在开发期不被微信拦截卡住，后端此时会优雅降级为**开发测试模拟号 (`13800xxxxxx`)** 存入数据库，确保整个业务流转畅通无阻。

### 3. 如何在正式上线时实现 100% 真实号码一致？
当你正式上线该小程序时，只需在后端的 `server/src/main/resources/application.yml` 中，将微信参数替换为你自己的真实小程序秘钥：
```yaml
wx:
  miniapp:
    appid: "你的真实小程序AppID"
    secret: "你的真实小程序AppSecret"
```
配置完成后，微信官方解密接口将自动激活，**数据库中写入的号码与手机微信弹窗展示的真实手机号将 100% 一字不差！**

## 📋 微信小程序账号申请、主体填写与工信部备案保姆级指南（上线必读）

游戏开黑陪练类目在微信生态中属于强监管敏感地带。为避免被微信官方拒审或封禁主体，请严格按照以下合规标准推进：

### 1. 主体类型选择：必须是个体工商户或企业主体（千万不要用个人）
* **为什么不能用个人主体？**
  - 个人主体**无法开通微信支付**，客户无法线上付款下单；
  - 个人主体无法选择“生活服务/咨询”类目，功能受到严重阉割。
* **初创推荐：个体工商户（成本最低、出照最快）**：
  - 各省政务服务网/政务 App（如“浙里办”、“爱山东”、“粤商通”等）全流程免费在线办理，1~3 天执照顺丰包邮到家；
  - 个体户无需开立对公银行账户，法人直接用个人实名微信扫脸认证，零维护成本。
* **经营范围填写技巧（非常关键！）**：
  - **建议包含**：`信息技术咨询服务`、`数字文化创意软件开发`、`体育健康服务`、`商务代理代办服务`、`互联网销售`；
  - ⚠️ **严禁出现**：`游戏代练`、`代打`、`租号`、`虚拟货币交易`等敏感词汇。

### 2. 小程序命名与简介避坑（第一道审查红线）
* ❌ **严禁出现的敏感词**：`陪玩`、`约玩`、`代练`、`代打`、`上分`、`带飞`、`美女陪聊`。
* ✅ **最容易过审的高通过率名称**：
  - `XX开黑搭子`
  - `XX电竞组队助手`
  - `XX游戏开黑搭子`
  - `XX电竞技能指导`
* **简介范例**：*“提供游戏玩家组队开黑、电竞玩法技巧交流与战术指导的在线工具助手。”*

### 3. 核心服务类目选择（免除特许行业资质的死穴）
* ❌ **千万不要碰的类目**：
  - `文娱 - 社交/论坛`（需要极难办理的《增值电信业务经营许可证 (ICP/EDI)》）；
  - `游戏 - 游戏服务平台`（需要网络文化经营许可证及游戏版号）。
* ✅ **免许可证的黄金过审类目**：
  - **首选类目**：`生活服务 - 商务服务` 或 `生活服务 - 咨询服务`；
  - **备选类目**：`体育 - 体育场馆/赛事/电竞`；
  - **所需资质**：仅需上传**营业执照彩色拍照 + 法人身份证**，无需任何额外特许批文，通常 1 个工作日内即可过审。

### 4. 工信部小程序备案全流程（国家强制，必须备案后才可上线）
微信认证通过后，直接在微信公众平台后台提交备案：
1. **材料准备**：营业执照原件清晰拍照、法人身份证正反面、法人微信扫脸；
2. **手机号要求**：
   - 负责人手机号**必须是运营商实名在法人名下**的手机号；
   - 应急联系人手机号**绝对不能和负责人手机号相同**；
3. **工信部短信核验（最容易超时的死穴）**：
   - 微信初审通过后，工信部官方系统（短信通道：`12381`）会向负责人手机下发带有 **6 位验证码** 的核验短信；

   - 各省通信管理局审核一般在 3~7 个工作日下发专属备案号（如：`粤ICP备xxxxxx号-1X`）。

### 5. 微信代码提审上架与安全规范
1. **微信官方内容安全接口接入（必须）**：
   - 用户的聊天文本、个性简介必须接入微信官方 `security.msgSecCheck`（文本防低俗过滤）；

2. **提审时 UI 文案规范**：

## 💰 真实财务核算与微信官方通道抽成（0.6%）避坑说明

在商业陪玩运营中，微信官方作为第三方底层支付通道，在每一笔交易中都会强行扣除**支付通道手续费**。如果财务账目没有将微信的扣点算进去，很容易导致账面虚高甚至活动期倒贴亏损。

### 1. 微信官方真实的收费底牌
* **玩家微信支付入账 (JSAPI 支付)**：
  - **扣除标准：0.6% (千分之六)**（微信对软件/生活服务类小程序的统一费率）；
  - **扣除方式：实时从本金中切走**。玩家付款 100 元，真正进入你商户号资金池的只有 **99.40 元**，0.60 元被微信官方当场截留。
* **陪玩师收益提现 (商家转账到零钱)**：
  - **目前政策：基本免收手续费 (0%)**。从商户号直接转账至陪练师个人微信零钱，目前官方不额外加收通道费。

  【微信官方扣走：0.30 元】               【商户号实收：49.70 元】
  (50.00 × 0.6% 支付通道费)                        │
